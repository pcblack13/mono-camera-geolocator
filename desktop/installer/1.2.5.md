# Mono Camera Geolocator 1.2.5

The recommended release for **all** users — every 1.2.x installation should
upgrade (older versions leave background processes running after each session).

## Fixed

- **Closing the app now truly closes it.** Previously the database, Redis and
  worker processes kept running in the background and slowed the computer until
  a reboot. They now shut down with the window (and any leftovers from older
  versions are cleaned up automatically at the next launch).
- **Windows starts correctly.** 1.2.3 crashed at the loading screen on every
  Windows machine ("applying database migrations"); the cause was a
  Windows-specific event-loop incompatibility, now fixed.
- **Large file uploads work.** DEM rasters and field videos of any size up to
  the 4 GB limit upload reliably — files picked in the desktop app are now read
  directly from disk instead of being loaded through memory (uploads over 2 GB
  previously failed silently).
- **The satellite map cannot go silently blank anymore.** A misconfigured
  Mapbox token is detected and ignored in favour of the built-in one, and if
  imagery ever fails for a real reason, the map shows the exact error message
  instead of empty tiles.
- **GCP tables always show a Point ID** — points without a code display their
  short database id, matching the editor.

## New

- **Live stream: local video sources.** The Live stream tab can now use HDMI
  capture cards and USB/USB-C cameras plugged into the machine ("Scan local
  devices"), and can display RTSP network cameras. The statistics panel shows
  the stream encoding (MJPEG, H264 source, …) and measured FPS. Devices are
  opened in MJPEG mode for full frame rate.

## Improved

- First launch no longer shows an "application not responding" dialog while it
  sets itself up.
- Every boot writes a full log (`boot.log` in the app data folder) and startup
  errors are shown as selectable, copyable text — for faster support.
- Windows: no more stray console windows; startup timeouts sized for antivirus
  scanning on first run.

## Install

Windows: run `MonoCameraGeolocator-Setup-1.2.5.exe` (first launch ~1 min).

Linux (Ubuntu/Debian):

```bash
sudo apt install ./mono-camera-geolocator_1.2.5_amd64.deb
```
