# Mono Camera Geolocator 1.2.6

A feature release, recommended for everyone on 1.2.x. Most of the work is in the
GCP editor — placing and adjusting points is faster and needs less typing — plus
per-photograph elevation models and a more honest live-stream panel.

## New

- **Points name themselves.** A new ground control point arrives already named
  `GCP-01`, `GCP-02`, and so on, so committing needs no typing at all. The
  pencil beside the name overrides it whenever you want, and imported names
  (`pt-95`, `Field corner NE`) are never renumbered — the sequence simply runs
  alongside them.
- **F1 commits a point.** With both endpoints placed, one key commits it. A full
  run of GCPs no longer needs the mouse to leave the photograph.
- **Both panels stay in step while you adjust a point.** In Auto mode, dragging
  the marker on the satellite map now moves the mark on the photograph to match,
  and dragging the photo mark moves the map marker — both through the solved
  camera. Manual mode is unchanged and still leaves each endpoint entirely in
  your hands.
- **Live predict.** Turn it on and the map follows your cursor across the
  photograph, showing where each pixel lands on the ground before you commit
  anything.
- **A DEM per photograph.** One photo can override the project elevation model
  with its own — set from its very first setup — while every other photo keeps
  the project surface. Its ground control points and its Auto GCP ray-cast then
  read that surface.
- **Project settings.** Name, description and the project DEM now live on their
  own page. Creating a project lands there first, and saved settings open
  read-only until you press Edit — so a look does not become an accidental
  change. The image setup page works the same way.
- **The DEM library can be tidied.** Processed DEMs stay reusable across
  projects, and can now be deleted from the DEM processing page. Projects
  already using one keep their own copy and are unaffected.
- **Esri World Imagery is selectable again**, alongside Mapbox and Google.

## Fixed

- **Adjusting a point moves it on both panels.** Editing a GCP could move the
  marker on the map while leaving the mark on the photograph where it was; the
  photo endpoint was being dropped on save. Both now travel together.
- **A disconnected camera says so.** If a capture device is unplugged or
  switched off mid-stream, the live panel now stops the video and states plainly
  that the device disconnected — previously the last frame simply froze, which
  was indistinguishable from a slow stream.
- **Live streams run at full frame rate.** The server was re-serving every
  source at a fixed 15 fps regardless of what the camera could do; the cap is
  now 30 by default and up to 60 for capture cards that support it.
- **Uncompressed capture devices are explained, not silently slow.** Devices are
  still asked for MJPEG; one that only offers a raw format (YUYV, greyscale)
  still streams, with a note explaining that a large uncompressed frame does not
  fit in USB 2.0 bandwidth and may run at a few frames per second.
- **Project settings could not be saved** — saving returned a server error
  caused by a timestamp read after the update; renaming a project from the list
  had the same latent fault.
- **Closing the app from a terminal no longer leaves a worker running.** Ctrl+C
  could leave the background task process alive after the database it depended
  on had already stopped.
- **Back navigation from DEM processing** said "Not found" when the page had
  been opened from project settings.
- **An empty project opens on its own page** instead of jumping straight to
  image setup, and says that it has no images yet.

## Improved

- Processing a DEM from a project or an image now offers to return exactly where
  you came from, with everything you had typed still in the form.
- The undo, redo and delete buttons appear only while a point is being placed or
  adjusted — the stage where they act on something — and they now act on the
  point's own endpoints.
- Pose diagnostics (a point that reprojects badly, a point outside the DEM) no
  longer interrupt with a toast on every click. They remain in the server's
  response for support and diagnosis.
- The satellite map's provider list is now decided by the server alone, so a
  provider enabled on the server always appears in the menu.
- Import and export icons in the GCP toolbar point the right way, and a manually
  adjusted point is marked with a pencil in the table.

## Note for existing installations

The provider list is read from the running copy's configuration, at
`~/.local/share/MonoCameraGeolocator/work/.env` on Linux — not from the source
tree. If a provider you expect is missing from the map settings, check
`LE_ALLOWED_PROVIDERS` in that file; an empty or absent line allows all of them.

## Install

Windows: run `MonoCameraGeolocator-Setup-1.2.6.exe` (first launch ~1 min).

Linux (Ubuntu/Debian):

```bash
sudo apt install ./mono-camera-geolocator_1.2.6_amd64.deb
```
