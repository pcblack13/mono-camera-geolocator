# Mono Camera Geolocator — installer download

Download the installer from the latest GitHub release (Windows + Linux):

https://github.com/Doctor13-st/GEO-1/releases/latest


# GOOGLE DRIVE:

https://drive.google.com/file/d/1lx5oxhF_M70vWMtpDM1z5x1f4GFYEvek/view?usp=drive_link

Then install (the file lands in `~/Downloads`; the `./` matters):

```bash
cd ~/Downloads
sudo apt install ./mono-camera-geolocator_*_amd64.deb
```

Windows: just run `MonoCameraGeolocator-Setup-*.exe`.

Launch from the applications menu ("Mono Camera Geolocator").
